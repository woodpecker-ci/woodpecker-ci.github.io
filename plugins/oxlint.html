Plugins / Oxlint

Oxlint

by Adam Lui
adamlui/drone-oxlint
Latest release: 1.7.0
Website
securityoxlintjavascripttypescriptcode-quality

Plugin to run Oxlint on your repo.

Quick start 

when:
  - event: manual
  - event: [pull_request, push]
    path: { include: ['**/*.{cjs,cts,js,jsx,mjs,mts,ts,tsx}'] }

steps:
  - name: oxlint
    image: adamlui/drone-oxlint:v1.7.0

Settings (21)

NOTE  YAML settings override matching config file settings.

Example

  - name: oxlint
    image: adamlui/drone-oxlint:v1.7.0
    settings:
      config: oxlint.config.ts
      warn: no-console
      deny: no-eval
      plugins: import nextjs
      max_warnings: 10
      debug: true
Oxlint (9)
Setting Description Default
config Path to an Oxlint or ESLint <9 config file. auto-detected
no_config Disable auto-discover config file. false
oxlint_args Additional raw args passed verbatim to the Oxlint CLI (e.g. --fix --quiet). none
plugins Whitespace-separated list of plugins to enable (e.g. nextjs import). none
plugins_disable Whitespace-separated list of plugins to disable (e.g. typescript). none
format Lint result output format (e.g. agent, json). default
base_branch Base branch that PRs are compared against. PR target branch
version Oxlint version to install. Accepts a SemVer pattern. latest
working_directory Directory to run Oxlint from. repo root
File matching (5)
Setting Description Default
files Whitespace-separated list of glob patterns to include (e.g. src/**). none
ignore_patterns Whitespace-separated list of glob patterns to exclude (e.g. dist/** build/**). none
ignore_path Path to an ignore file (e.g. .oxlintignore, .eslintignore). none
extensions Comma-separated file extensions to lint on pull requests. cjs,cts,js,jsx,mjs,mts,ts,tsx
all_files Lint all files, not just changed files on pull requests. false
Rules & warnings (5)
Setting Description Default
allow Whitespace-separated list of rules or categories to allow. none
warn Whitespace-separated list of rules or categories to warn. none
deny Whitespace-separated list of rules or categories to deny. none
deny_warnings Fail if any warnings are emitted (alias for max_warnings: 0). false
max_warnings Fail if more than this many warnings are emitted. none
Plugin (2)
Setting Description Default
debug Enable shell tracing (set -x) of the plugin entrypoint. false
never_fail Exit 0 regardless of lint errors (so CI step always passes). false

Dev setup

You'll need Docker and (for local pipeline testing) the Drone CLI.

git clone https://codeberg.org/adamlui/drone-oxlint.git
cd drone-oxlint

The plugin is built from the Dockerfile and runs via src/entrypoint.sh + src/utils.sh. If you change any of these, rebuild the image:

docker build -t adamlui/drone-oxlint:dev .

Test your change

Run the example pipeline locally:

drone exec --pipeline default

No Drone CLI? Test the image directly:

docker run --rm -v "$PWD:/app" -w /app adamlui/drone-oxlint:dev
