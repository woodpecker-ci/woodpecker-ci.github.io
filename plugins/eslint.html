Plugins / ESLint

ESLint

by Adam Lui
adamlui/drone-eslint
Latest release: 1.4.0
Website
securityeslintjavascripttypescriptcode-quality

Run ESLint on your repo.

Quick start 

when:
  - event: manual
  - event: [pull_request, push]
    path: { include: ['**/*.{cjs,cts,js,jsx,mjs,mts,ts,tsx}'] }

steps:
  - name: eslint
    image: adamlui/drone-eslint:v1.4.0

Settings (23)

NOTE  YAML settings override matching ESLint config file settings.

Example

  - name: eslint
    image: adamlui/drone-eslint:v1.4.0
    settings:
      config: eslint.config.js
      deny: no-eval
      warn: no-console
      extensions: js,jsx,ts,tsx
      max_warnings: 10
      debug: true
ESLint (5)
Setting Description Default
config Path to an ESLint config file. auto-detected
eslint_args Additional raw args passed verbatim to the ESLint CLI (e.g. --fix --quiet). none
base_branch Base branch that PRs are compared against. PR target branch
version ESLint version to install. Accepts a SemVer pattern. latest
working_directory Directory to run ESLint from (alias root_dir). repo root
File matching (5)
Setting Description Default
files Whitespace-separated list of glob patterns to include (e.g. src/**). none
ignore_patterns Whitespace-separated list of glob patterns to exclude (e.g. dist/** build/**). none
ignore_file Path to an ignore file (e.g. .eslintignore). none
extensions Comma-separated file extensions to lint. cjs,cts,js,jsx,mjs,mts,ts,tsx
all_files Lint all files, not just changed files on pull requests. false
Rules & warnings (5)
Setting Description Default
allow Whitespace-separated list of rules to set to off. none
warn Whitespace-separated list of rules to set to warn. none
deny Whitespace-separated list of rules to set to error. none
deny_warnings Fail if any warnings are emitted (alias for max_warnings: 0). false
max_warnings Fail if more than this many warnings are emitted. none
Findings (6)
Setting Description Default
format Lint findings output format (html, json, json-with-metadata, stylish). stylish
color Colorize findings. true
quiet Report errors only (suppress warnings). false
annotations Post findings as inline annotations via Reviewdog (requires reporter + a forge API token). false
reporter Reviewdog reporter for annotations (e.g. github-pr-review, gitea-pr-review). none
fail_level Reviewdog fail level (any, error, info, warning). error
Plugin (2)
Setting Description Default
debug Enable shell tracing (set -x) of the plugin entrypoint. false
never_fail Exit 0 regardless of lint errors (so CI step always passes). false

Dev setup

To build/test changes, you'll need Docker.

git clone https://codeberg.org/adamlui/drone-eslint.git
cd drone-eslint

The plugin is built from the Dockerfile and runs via src/**/*.sh files. If you change any of them, rebuild the image:

docker build -t adamlui/drone-eslint:dev .

Test your change 

docker run --rm -v "$PWD:/app" -w /app adamlui/drone-eslint:dev
